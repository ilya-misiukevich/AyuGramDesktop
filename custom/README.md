# Свои изменения поверх AyuGram

Код AyuGram в репозитории не меняется. Всё своё лежит здесь и накладывается при сборке (`.github/workflows/build.yml`).

| Что | Где |
|---|---|
| Изменения кода AyuGram | `patches/*.patch` |
| Изменения lib_ui (накладываются внутри `Telegram/lib_ui`) | `patches/lib_ui/*.patch` |
| Обход ошибок сборки библиотек | `prepare.patch` |
| Страница выбора иконки (копируется в `Telegram/SourceFiles/ayu/ui/boxes/`) | `src/` |
| Иконки: папка = иконка, внутри `app.png` 256px и `app_icon.ico` | `icons/` |
| Официальные картинки Telegram | `brand/art/` |

Патчи:
- `names.patch` — имя exe, свойства файла, ярлыки, заголовки, ссылки, окно ошибки;
- `original-look.patch` — экран входа, «О программе», без бейджей, ToS и доната, превью от своего аккаунта;
- `lang.patch` — AyuGram → Telegram во всех текстах интерфейса, включая скачанные переводы;
- `app-icon.patch` — строка «Иконка приложения» в настройках, открывающая страницу выбора, иконка по умолчанию (Sky), её подстановка, если сохранённой иконки больше нет, и чёткие png-иконки при масштабе больше 100%;
- `settings-links.patch` — блок Links на странице AyuGram: строка Channel ведёт на @AyuGramReleases;
- `lib_ui/smooth-wheel.patch` — плавная прокрутка колесом мыши везде: окна, настройки, списки, список чатов и сами чаты (`ScrollArea` и `ElasticScroll`, анимация из профиля Desktop). Тачпад и программные переходы не трогает.

Новая иконка: положить папку в `icons/` и добавить её в список в `src/app_icon_box.cpp`.

Если AyuGram изменит код и патч перестанет ложиться, сборка упадёт на шаге «Apply custom changes» с именем файла. Патч пересоздаётся так: наложить патчи на свежий код, поправить, `git diff --full-index -- <файлы> > custom/patches/<имя>.patch`. Для lib_ui то же самое внутри `Telegram/lib_ui`, результат в `custom/patches/lib_ui/`.
